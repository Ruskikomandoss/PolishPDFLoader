## Project Overview

`polish-pdf-loader` is a Python library that wraps PyMuPDF, pdfplumber, and pypdf to correctly extract text from Polish-language PDFs. The core problem it solves: PDF tools often decode CP1250-encoded bytes as CP1252, producing garbled characters (`ś→œ`, `ł→³`, `ą→¹`). The fix is `text.encode('cp1252').decode('cp1250')`, applied only when the garbled pattern is detected via `is_polish_garbled()`.

All public loaders are `langchain_core.document_loaders.BaseLoader` subclasses, making them drop-in replacements for `PyMuPDFLoader` etc.

## Architecture

```
polish_pdf_loader/
  encoding.py        # detect_and_repair(), is_polish_garbled(), repair_cp1250_as_latin1()
  postprocess.py     # PostprocessConfig, postprocess() — ligatures, whitespace, hyphens
  loaders.py         # PolishPDFLoader (BaseLoader) + alias classes
  cli.py             # click CLI: polish-pdf <file> [--backend] [--pages] [--out]
  backends/
    pymupdf_backend.py     # load_pdf_pymupdf()
    pdfplumber_backend.py  # load_pdf_pdfplumber()
    pypdf_backend.py       # load_pdf_pypdf()
```

Each backend returns `list[dict]` with keys `page`, `text`, `metadata`. `PolishPDFLoader.lazy_load()` dispatches to the right backend via `importlib`, applies `postprocess()`, and yields `Document` objects.

## Key Design Decisions

- `is_polish_garbled` requires at least one **anchor marker** (`œ`, `Ÿ`, `Œ`) before firing — this prevents false positives on academic PDFs with superscript digits (`¹`, `³`).
- `æ` and `ê` are intentionally excluded from garble detection to avoid false positives on French/Latin loanwords common in Polish text. Use `repair_cp1250_as_latin1()` directly when you know input is garbled.
- Each backend is an optional install extra: `pip install polish-pdf-loader[pymupdf]`.
- Test fixture (`tests/data/sample_polish.pdf`) is auto-generated by `tests/data/generate_fixture.py` via `conftest.py` if absent.
